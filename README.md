One single-line joke about office life, under 200 characters. The entry program
writes the joke to `/output/entry.txt`.

> Our printer only jams when you're late, which makes it the most punctual thing in the building.

- Competition: [One-Line Office Jokes on make.fun](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc)

## Run

```sh
npx tsx main.ts   # or: node --experimental-strip-types main.ts
cat /output/entry.txt
```
